Testing

Testing is set to evaluate:

  • style with flake8,

  • typing with mypy,

  • valid function return values and behaviors with hypothesis, and

  • test coverage using coverage.

Windows

Run test.bat in the test directory.

Linux

Run test.sh in the test directory.
