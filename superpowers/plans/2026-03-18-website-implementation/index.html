    Tafra Website Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Task 7: GitHub Pages deploy workflow

    Files: - Create: .github/workflows/docs.yml

    • [ ] Step 1: Create .github/workflows/docs.yml
    name: Deploy Docs

on:
  push:
    branches: [master]
    paths:
      - 'docs/**'
      - 'mkdocs.yml'
      - 'tafra/**'

permissions:
  contents: write

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v5
        with:
          fetch-depth: 0
      - uses: actions/setup-python@v6
        with:
          python-version: "3.12"
      - run: pip install mkdocs-material "mkdocstrings[python]" && pip install -e .
      - run: mkdocs build --strict
      - run: mkdocs gh-deploy --force
