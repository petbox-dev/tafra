    GroupBy/Transform/Join Performance Optimization

    For agentic workers: REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Replace O(groups x rows) boolean mask construction in GroupBy/Transform/IterateBy with index-based grouping, replace Python-list accumulation in InnerJoin/LeftJoin with numpy pre-allocation, and adopt numpy 2.1's StringDType throughout.

    Architecture: Extract a shared _build_group_indices() helper that computes group membership once via np.unique+return_inverse (or equivalent for multi-column). All group operations (GroupBy, Transform, IterateBy) use the resulting index arrays instead of per-group boolean masks. Joins switch from Python list accumulation to numpy array building with np.concatenate. String columns migrate from object dtype to np.dtypes.StringDType(), with StringDType(na_object=None) for nullable contexts (LeftJoin).

    Tech Stack: numpy >=2.1 (already required in pyproject.toml), no new deps.

    Task 1: Add _build_group_indices to GroupSet

    This is the core primitive. It replaces _unique_groups for all consumers.

    Files: - Modify: tafra/group.py:148-159 - Test: test/test_tafra.py

    Design:

    For single-column groups, use np.unique(col, return_inverse=True) directly. For multi-column groups, build a structured array or use np.unique on tupled rows via np.array(list(zip(...))) with a void dtype key, preserving insertion order.

    The return type is Tuple[List[Tuple], List[np.ndarray]]: - unique: list of tuples of group values (same contract as old _unique_groups) - group_indices: list of integer index arrays, one per group (the rows belonging to each group)

    This replaces the pattern: 

    which_rows = np.full(tafra._rows, True)
for val, col in zip(u, self.group_by_cols):
    which_rows &= tafra._data[col] == val

    With: 

    rows = group_indices[i]  # int array of row positions

    The key insight: np.unique(..., return_inverse=True) gives us the group label for every row. We then use np.argsort + np.split on the inverse to get per-group index arrays in one pass. This is O(n log n) total instead of O(groups x n).

    @staticmethod
def _build_group_indices(
    tafra: 'Tafra', columns: Iterable[str]
) -> Tuple[List[Tuple[Any, ...]], List[np.ndarray[Any, Any]]]:
    """
    Build per-group row index arrays in a single pass.

    Returns (unique, group_indices) where:
    - unique: list of tuples of group-by values, in first-seen order
    - group_indices: list of int arrays (row positions for each group)
    """
    cols = list(columns)
    if len(cols) == 1:
        data = tafra._data[cols[0]]
        # np.unique sorts; we need first-seen order
        _, first_idx, inverse = np.unique(data, return_index=True, return_inverse=True)
        # reorder by first occurrence
        order = np.argsort(first_idx)
        # map from sorted-unique-index to first-seen-index
        rank = np.empty_like(order)
        rank[order] = np.arange(len(order))
        remapped = rank[inverse]

        n_groups = len(order)
        sorted_row_indices = np.argsort(remapped, kind='stable')
        counts = np.bincount(remapped, minlength=n_groups)
        splits = np.cumsum(counts[:-1])
        group_indices = np.split(sorted_row_indices, splits)

        unique_vals = data[first_idx[order]]
        unique = [(v,) for v in unique_vals]
    else:
        # multi-column: build tuple keys, use dict for first-seen order
        keys = list(zip(*(tafra._data[col] for col in cols)))
        seen: Dict[Any, List[int]] = {}
        for i, k in enumerate(keys):
            if k in seen:
                seen[k].append(i)
            else:
                seen[k] = [i]
        unique = list(seen.keys())
        group_indices = [np.array(v, dtype=np.intp) for v in seen.values()]

    return unique, group_indices

    • [ ] Step 3: Rewrite InnerJoin.apply()

    Strategy: For all-equi joins, build a dict mapping right-key-tuples to row index lists. Then iterate left rows, look up matching right indices, and build result arrays via np.concatenate.

    def apply(self, left_t: 'Tafra', right_t: 'Tafra') -> 'Tafra':
    left_cols, right_cols, ops = list(zip(*self.on))
    self._validate(left_t, left_cols)
    self._validate(right_t, right_cols)
    self._validate_dtypes(left_t, right_t)
    self._validate_ops(ops)

    _on = tuple(
        (left_col, right_col, JOIN_OPS[op])
        for left_col, right_col, op in self.on
    )

    # determine output columns
    join_cols: List[str] = [
        c for c in chain(left_t._data.keys(), right_t._data.keys())
        if not self.select or c in self.select
    ]
    # right-to-left so left dtypes overwrite
    dtypes: Dict[str, str] = {
        c: d for c, d in chain(right_t._dtypes.items(), left_t._dtypes.items())
        if c in join_cols
    }
    # de-duplicate column list preserving order (left wins)
    seen_cols: Dict[str, None] = {}
    for c in join_cols:
        seen_cols[c] = None
    join_cols = list(seen_cols.keys())

    all_equi = all(op_str == '==' for _, _, op_str in self.on)

    if all_equi:
        # hash join: build right index
        right_key_cols = [right_t._data[rc] for _, rc, _ in self.on]
        right_keys = list(zip(*right_key_cols)) if len(right_key_cols) > 1 \
            else [(v,) for v in right_key_cols[0]]
        right_index: Dict[Tuple[Any, ...], List[int]] = {}
        for i, k in enumerate(right_keys):
            if k in right_index:
                right_index[k].append(i)
            else:
                right_index[k] = [i]

        left_key_cols = [left_t._data[lc] for lc, _, _ in self.on]
        left_indices: List[int] = []
        right_indices: List[int] = []

        for i in range(left_t._rows):
            lk = tuple(col[i] for col in left_key_cols)
            matches = right_index.get(lk)
            if matches is not None:
                left_indices.extend([i] * len(matches))
                right_indices.extend(matches)

        if len(left_indices) == 0:
            return Tafra(
                {c: np.array([], dtype=left_t._data[c].dtype)
                 if c in left_t._data
                 else np.array([], dtype=right_t._data[c].dtype)
                 for c in join_cols},
                dtypes
            )

        li = np.array(left_indices, dtype=np.intp)
        ri = np.array(right_indices, dtype=np.intp)

        result = {}
        for c in join_cols:
            if c in left_t._data:
                result[c] = left_t._data[c][li]
            else:
                result[c] = right_t._data[c][ri]

        return Tafra(result, dtypes)

    else:
        # fallback: original nested-loop approach with hoisted allocation
        right_rows = np.empty(right_t._rows, dtype=bool)
        join: Dict[str, List[Any]] = {c: [] for c in join_cols}

        for i in range(left_t._rows):
            right_rows[:] = True
            for left_col, right_col, op in _on:
                right_rows &= op(left_t._data[left_col][i], right_t._data[right_col])

            right_count = np.sum(right_rows)
            if right_count <= 0:
                continue

            for column in join_cols:
                if column in left_t._data:
                    join[column].extend([left_t._data[column][i]] * right_count)
                elif column in right_t._data:
                    join[column].extend(right_t._data[column][right_rows])

        return Tafra(
            {c: np.array(v) for c, v in join.items()},
            dtypes
        )

    join_cols: List[str] = [
        c for c in chain(left_t._data.keys(), right_t._data.keys())
        if not self.select or c in self.select
    ]
    dtypes: Dict[str, str] = {
        c: d for c, d in chain(right_t._dtypes.items(), left_t._dtypes.items())
        if c in join_cols
    }
    seen_cols: Dict[str, None] = {}
    for c in join_cols:
        seen_cols[c] = None
    join_cols = list(seen_cols.keys())

    all_equi = all(op_str == '==' for _, _, op_str in self.on)

    if all_equi:
        right_key_cols = [right_t._data[rc] for _, rc, _ in self.on]
        right_keys = list(zip(*right_key_cols)) if len(right_key_cols) > 1 \
            else [(v,) for v in right_key_cols[0]]
        right_index: Dict[Tuple[Any, ...], List[int]] = {}
        for i, k in enumerate(right_keys):
            if k in right_index:
                right_index[k].append(i)
            else:
                right_index[k] = [i]

        left_key_cols = [left_t._data[lc] for lc, _, _ in self.on]

        # collect result pieces
        result_parts: Dict[str, List[Any]] = {c: [] for c in join_cols}
        has_null = False

        for i in range(left_t._rows):
            lk = tuple(col[i] for col in left_key_cols)
            matches = right_index.get(lk)

            if matches is not None:
                n = len(matches)
                ri_arr = matches
                for c in join_cols:
                    if c in left_t._data:
                        result_parts[c].extend([left_t._data[c][i]] * n)
                    else:
                        for ri in ri_arr:
                            result_parts[c].append(right_t._data[c][ri])
            else:
                has_null = True
                for c in join_cols:
                    if c in left_t._data:
                        result_parts[c].append(left_t._data[c][i])
                    else:
                        result_parts[c].append(None)

        if has_null:
            for c in join_cols:
                if c not in left_t._data and dtypes.get(c) != 'object':
                    dtypes[c] = 'object'

        return Tafra(
            {c: np.array(v) for c, v in result_parts.items()},
            dtypes
        )

    else:
        # fallback: original approach with hoisted allocation
        right_rows = np.empty(right_t._rows, dtype=bool)
        join: Dict[str, List[Any]] = {c: [] for c in join_cols}

        for i in range(left_t._rows):
            right_rows[:] = True
            for left_col, right_col, op in _on:
                right_rows &= op(left_t._data[left_col][i], right_t._data[right_col])

            right_count = np.sum(right_rows)

            for column in join_cols:
                if column in left_t._data:
                    join[column].extend([left_t._data[column][i]] * max(1, right_count))
                elif column in right_t._data:
                    if right_count <= 0:
                        join[column].append(None)
                        if dtypes[column] != 'object':
                            dtypes[column] = 'object'
                    else:
                        join[column].extend(right_t._data[column][right_rows])

        return Tafra(
            {c: np.array(v) for c, v in join.items()},
            dtypes
        )

    Chunk 3: Adopt numpy 2.1 StringDType

    Background

    numpy 2.1 introduced np.dtypes.StringDType() — a proper variable-length string dtype (kind 'T'). This replaces the legacy pattern of storing strings in object dtype arrays. Key properties verified on numpy 2.2.6:

    • np.array(['a', 'b'], dtype=np.dtypes.StringDType()) → dtype StringDType(), kind 'T'
    • np.full(3, 'test', dtype=np.dtypes.StringDType()) works
    • np.unique, fancy indexing, boolean masking, np.append, np.empty_like all work
    • StringDType(na_object=None) supports None values (needed for LeftJoin null fill)
    • type(arr[0]).__name__ returns 'str' (same as object-array-of-strings)
    • _format_dtype already returns 'str' for StringDType (the 'str' in name check hits)
    • np.asarray(['a', 'b']) still produces fixed-width <U by default — explicit dtype needed
    • tafra already requires numpy>=2.1 in pyproject.toml
