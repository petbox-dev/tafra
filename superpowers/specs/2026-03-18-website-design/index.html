    Tafra Website Design Spec

    Overview

    Replace the existing Sphinx/ReadTheDocs documentation with a unified marketing landing page + documentation site, built with MkDocs Material and deployed to GitHub Pages at https://petbox-dev.github.io/tafra/.

    Decisions

    Decision Choice Rationale
    Site type Unified landing page + docs (option C) Single site, single toolchain, no custom domain needed
    Visual style Clean + minimal (option B) Matches tafra's identity as the minimalist dataframe library
    Static site generator MkDocs Material (option A) Industry standard for polished Python project sites; used by Polars, Pydantic, FastAPI
    Build approach Material custom homepage override (approach A) Single toolchain, landing page via Jinja template, docs in Markdown
    Logo Geometric mark + wordmark (option B) Abstract grid/table mark representing "innards of a dataframe"

    Color System

    Token Value Usage
    --bg-white #ffffff Primary background
    --bg-alt #f8fafa Alternating section background
    --bg-code #f1f5f9 Code block background
    --text-primary #1a1a2e Headings, body text
    --text-secondary #475569 Subtitles, descriptions
    --text-muted #7c8db0 Labels, captions, footer text
    --accent #0d9488 Links, buttons, highlights (teal-600)
    --accent-hover #0f766e Hover states (teal-700)
    --accent-light #ccfbf1 Accent backgrounds (benchmark bars, badges)
    --accent-subtle #f0fdfa Feature icon backgrounds
    --border #e2e8f0 Card borders, dividers

    Syntax highlighting: - Keywords: #7c3aed (violet) - Functions: #0d9488 (teal, matches accent) - Strings: #059669 (emerald-600) - Numbers: #d97706 (amber) - Comments: #7c8db0 (muted)

    Typography: - Headings/body: Inter (fallback: system sans-serif) - Code: JetBrains Mono (fallback: Fira Code)

    Reference mockup: docs/color-preview.html

    Landing Page Sections

    1. Navbar (sticky)

    • Logo (geometric mark + "tafra" wordmark), left-aligned
    • Nav links: Docs | Tutorials | API | GitHub
    • Teal accent underline on active link

    2. Hero

    • Heading: "The innards of a dataframe." (accent color on "innards")
    • Subheading: "A minimalist Python dataframe library — lightweight, fast, backed by numpy arrays."
    • CTA buttons: pip install tafra (copy-to-clipboard) | Get Started →
    • Compact syntax-highlighted code example: Tafra construction + group_by (~8 lines)

    3. Feature Cards (3-column grid)

    1. Minimalist — "Dict of numpy arrays. No magic, no complexity."
    2. Fast — "Vectorized aggregations, optional C acceleration, single-pass grouped ops."
    3. SQL-Style Ops — "GroupBy, Transform, Inner/Left/Cross Join — familiar operations, zero overhead."

    4. Benchmarks Strip

    • Table or horizontal bar chart: tafra vs pandas vs polars
    • Data sourced from test/bench_vs_pandas_vs_polars.py
    • Tafra row highlighted in accent color

    5. Quick Comparison

    • Side-by-side code blocks: pandas way vs tafra way for the same operation
    • Tafra block has accent-colored border

    6. Footer

    • MIT License | GitHub | PyPI | "Built with MkDocs Material"

    MkDocs Configuration

    Skeleton mkdocs.yml:

    site_name: tafra
site_url: https://petbox-dev.github.io/tafra/
repo_url: https://github.com/petbox-dev/tafra
repo_name: petbox-dev/tafra

theme:
  name: material
  custom_dir: docs/overrides
  palette:
    scheme: default
    primary: teal
    accent: teal
  font:
    text: Inter
    code: JetBrains Mono
  icon:
    repo: fontawesome/brands/github
  features:
    - navigation.tabs
    - navigation.sections
    - content.code.copy

extra_css:
  - stylesheets/extra.css

plugins:
  - search
  - mkdocstrings:
      handlers:
        python:
          options:
            show_source: true
            show_root_heading: true

nav:
  - Home: index.md
  - Getting Started: getting-started.md
  - Tutorials:
    - tutorials/index.md
    - Iris: tutorials/iris.md
    - Titanic: tutorials/titanic.md
    - Time Series: tutorials/timeseries.md
  - User Guide:
    - guide/construction.md
    - guide/column-ops.md
    - guide/groupby-partition.md
    - guide/joins.md
    - guide/chunking.md
  - API Reference: api.md
  - Benchmarks: benchmarks.md
  - Changelog: changelog.md

    Custom homepage wiring

    The landing page override requires three pieces: 1. custom_dir: docs/overrides in mkdocs.yml theme config (above) 2. docs/overrides/home.html extends main.html and overrides the content block 3. docs/index.md front-matter specifies the template: 

    ---
template: home.html
---

    CI/CD & Deployment

    GitHub Actions workflow (.github/workflows/docs.yml)

    • Trigger: push to master touching docs/**, mkdocs.yml, or tafra/**
    • Permissions: contents: write (required for mkdocs gh-deploy to push gh-pages branch)
    • Steps:
    • Checkout repo
    • Setup Python, install mkdocs-material, mkdocstrings[python]
    • mkdocs build --strict
    • mkdocs gh-deploy --force
    • GitHub Pages source: gh-pages branch, / (root)

    Existing CI updates

    • Remove the docs job from .github/workflows/ci.yml (currently runs sphinx-build)
    • Replace with mkdocs build --strict for PR validation (build-only, no deploy)
    • Remove docs/requirements.txt (Sphinx deps) — MkDocs deps installed inline in workflow

    URL structure

    • / — landing page
    • /getting-started/ — getting started guide
    • /tutorials/iris/ — tutorial pages
    • /guide/construction/ — user guide pages
    • /api/ — API reference
    • /benchmarks/ — performance data
    • /changelog/ — version history

    ReadTheDocs transition

    • Keep .readthedocs.yml temporarily for existing link continuity
    • Add redirect/banner on RTD pointing to GitHub Pages
    • Remove RTD config after migration period
